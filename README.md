# Перегрузка документа (1С)

Внешняя обработка для 1С:Предприятие 8.3 (управляемые формы).
Выгружает любой документ конфигурации в текстовый файл и создаёт по этому файлу новый документ — в той же или в другой базе.

## Как пользоваться

1. Выбрать документ и путь к файлу.
2. **Выгрузить документ** — в файл записываются шапка, заполненные реквизиты и табличные части.
3. **Просмотр файла** — открыть получившийся файл.
4. **Загрузить документ** — создать новый документ из файла. Если исходный документ был проведён, новый тоже проводится; если провести не удалось, документ записывается без проведения и показывается причина.

## Формат файла

Первая строка — вид, номер и дата документа, вторая — признак проведения.
Дальше — заполненные реквизиты в виде `Синоним реквизита: [Тип]значение`.

```
Реализация товаров и услуг № 0000-000123 от 15.03.2024 12:00:00
Проведен: Да
Контрагент: [Справочник.Контрагенты]{00-000045}ООО "Ромашка"
Комментарий: [Строка]Отгрузка<ПС>по договору
[ТабличнаяЧасть: Товары]
[НоваяСтрока]
Номенклатура: [Справочник.Номенклатура]{00-000012}Бумага А4
Количество: [Число]10
[КонецТабличнойЧасти]
```

| Тип значения | Запись в файле |
|---|---|
| Строка | `[Строка]текст` (перевод строки заменяется на `<ПС>`) |
| Число, Булево, Дата | `[Число]10.5`, `[Булево]Да`, `[Дата]15.03.2024 12:00:00` |
| Справочник, план видов характеристик, план счетов, план видов расчёта | `[Вид.Имя]{Код}Наименование` |
| Документ | `[Документ.Имя]{Номер\|Дата}Представление` |
| Перечисление | `[Перечисление.Имя]Значение` |

## Как устроено

Весь код — в модуле формы `src/ПерегрузкаДокумента/Forms/Форма/Ext/Form/Module.bsl`.

**Выгрузка**
- `СформироватьТекстДокументаНаСервере` — обходит реквизиты и табличные части документа по метаданным и собирает строки файла
- `СериализоватьЗначениеНаСервере` — превращает значение в строку с меткой типа; тип ссылки определяется через `Метаданные.НайтиПоТипу`

**Загрузка**
- `СоздатьДокументИзТекстаНаСервере` — находит вид документа по синониму из первой строки, создаёт документ и построчно разбирает файл
- `ПолучитьКартуРеквизитовНаСервере` — соответствие «синоним реквизита → имя» для шапки и для каждой табличной части
- `ПрочитатьЗначениеИзСтрокиНаСервере` — восстанавливает значение по метке типа; ссылки ищутся по коду, затем по наименованию, документы — по номеру и дате
- `МенеджерОбъектаНаСервере` — возвращает менеджер (`Справочники[…]`, `ПланыСчетов[…]` и т. д.) по виду объекта

## Ограничения

- Номер документа не переносится — новый документ получает номер по автонумерации
- Если ссылочный объект не найден в базе по коду и наименованию, реквизит остаётся пустым
- Реквизиты сопоставляются по синониму, поэтому синонимы в базе-приёмнике должны совпадать

## Сборка .epf из исходников

Конфигуратор → открыть любую внешнюю обработку → «Действия» → «Загрузить из файлов…» → выбрать `src/ПерегрузкаДокумента.xml` → «Файл» → «Сохранить как…» `.epf`.

1С:ERP Управление предприятием 2 (демо-база), платформа 8.3.
